# Rajlaxmi Jewellers — Premium Website

A mobile-first, multi-page static jewellery storefront concept using HTML, CSS and vanilla JavaScript. Designed for GitHub Pages; no backend or build process required.

## Pages
- Home — Diwali 2026 hero, collection cards, featured clickable designs, festive edit and brand story
- Collections — category filters, search, and clickable jewellery cards
- Product details — individual design detail view using `product.html?id=<product-id>` with WhatsApp enquiry
- Bridal, Offers, About, Gallery, Contact
- Craftsmanship, Jewellery Care, FAQs, Privacy Policy, Terms & Conditions, Refund & Exchange Policy, 404

## Jewellery catalogue interactions
The catalogue includes illustrative entries for Gold Jewellery, Mangalsutra, Bridal Jewellery, Diamond Jewellery, Earrings, Bangles & Bracelets, Pendants and Festive Jewellery. Product cards open their own detail view. The detail view has a WhatsApp enquiry link containing the selected design's name and category.

## Important production notes
- Product imagery and descriptions are illustrative website content, not a verified inventory or offer list.
- Confirm the shop's actual address, contact details, product availability, pricing, materials, purity, hallmark claims and all policy text before launch.
- The contact form opens WhatsApp with a prefilled message; the customer must press Send. This static site does not store form submissions.
- External map service opens Google Maps. All jewellery and showroom image files used in page layouts are included locally under `assets/images/`.

## Deploy on GitHub Pages
Upload the contents of this folder to the repository root and enable GitHub Pages for the desired branch/root. No build command is needed.
